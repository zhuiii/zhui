# 饮水记录

在电脑浏览器里使用的桌面小应用。按上海时间记录今天喝了多少水，对照每日计划，并在到点时提醒喝水。没有服务器，数据只写在这台浏览器的 localStorage 里。

## 运行

```bash
python3 -m http.server 8765
```

打开 http://127.0.0.1:8765

也可以直接打开 `index.html`。系统通知需要安全上下文（例如上面的本机网址）以及浏览器的通知权限；不授权时，页面内的倒计时和提醒条仍然可用。

## 测试

```bash
node --test
```

日期边界、今日合计、计划和提醒排程在 `tests/logic.test.js`。
