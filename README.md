# 饮水记录

在电脑浏览器里使用的桌面小应用。按上海时间记录今天喝了多少水，按你自己定的喝水方案在指定时间提醒，并提供日、周、月统计图。没有服务器，数据只写在这台浏览器的 localStorage 里。

- 记录：点 200 / 300 / 400 / 500 毫升，或填自定义毫升，按现在的时间记下。
- 喝水方案：自己设定时间点（24 小时制）、毫升、名称和备注。方案合计就是每天的计划，不用另外设置。
- 提醒：打开开关后，到方案里的时间点会在页面里提醒，并在已授权时发系统通知。
- 统计：日（按小时）、周（最近 7 天）、月（本月每天），周和月图上有每日计划虚线。

## 运行

```bash
python3 -m http.server 8765
```

打开 http://127.0.0.1:8765

也可以直接打开 `index.html`。系统通知需要安全上下文（例如上面的本机网址）以及浏览器的通知权限；不授权时，页面内的倒计时和提醒条仍然可用。

## 测试

```bash
node --test
```

日期边界、今日合计、方案和提醒排程在 `tests/logic.test.js`。
